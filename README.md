# Gavin Yanez e-Portfolio

This package contains a Quarto source project and a ready-to-publish `docs/` directory. The source files are `_quarto.yml`, `*.qmd`, `posts/`, `styles.css`, `headshot.png`, and `resume.pdf`.

## Publish with GitHub Pages

1. Create the GitHub repository `Gavin_Yanez` under the `Gavin-Yanez` account.
2. Upload the **contents of this folder** to the root of that repository (including `docs/`). Alternatively, push with Git.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/docs`, then save.
4. Wait for deployment and visit `https://gavin-yanez.github.io/Gavin_Yanez/` in a private window. Check Home, Projects, Resume, the PDF, photo, email, and LinkedIn.
5. Submit the working public URL in Blackboard.

If you later use Quarto, run `quarto render` in this directory before committing updates. Quarto will regenerate `docs/` from the QMD source. The two posts are starter examples and should be replaced with actual projects when available.
